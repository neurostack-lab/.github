# НейроСтек Lab

Open-source инструменты и эксперименты с ИИ от Telegram-канала [**НейроСтек**](https://t.me/neurostack_news).
Сами тестируем новые модели, честно публикуем замеры и выкладываем то, чем пользуемся.

## Проекты

| Проект | Что делает |
|---|---|
| [**free-llm-ru**](https://github.com/neurostack-lab/free-llm-ru) | Какие бесплатные LLM API реально работают: 28 моделей у 9 провайдеров, наш замер на русском, коде и отклике. Где брать ключи, какие лимиты, что не работает. |
| [**ollama-ru-bench**](https://github.com/neurostack-lab/ollama-ru-bench) | Одной командой проверяет модель из Ollama (локально или Ollama Cloud): русский язык, код на настоящих автотестах, арифметика, формат ответа, скорость. Код написала модель Beam от Reflection за один запрос, мы проверили его и исправили один баг. |

## Как мы работаем

- **Только замеры.** Цифры в README и постах — из наших собственных прогонов, с датой и условиями.
- **Не скрываем, кто писал код.** Если проект написала модель, это указано в README вместе с нашими правками.
- **Без лишнего.** Минимум зависимостей, всё запускается одной командой.
